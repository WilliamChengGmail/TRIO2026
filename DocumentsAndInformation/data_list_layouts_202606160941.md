# DataListPage 版面模式比較

> 設定項：`system_settings.data_list_layout`  
> 可選值：`card` | `compact` | `table`

---

## 快速概覽

| 特性 | Card | Compact | Table |
|------|------|---------|-------|
| **行高** | ~80px | ~50px (padding 14px) | ~40px (padding 10px) |
| **資訊密度** | ★★☆ 最豐富 | ★★★ 密集 | ★★★ 密集 + 排序 |
| **排序功能** | ✗ | ✗ | ✓ 點擊表頭排序 |
| **表頭列** | ✗ | ✗ | ✓ 固定表頭 |
| **交替底色** | ✗ | ✗ | ✓ 奇偶行 |
| **適用場景** | 觸控瀏覽 | 快速掃描 | 資料分析 |

---

## Card 模式 (`card`)

**設計定位**：資訊最完整，觸控友善，適合少量紀錄的日常瀏覽。

### 視覺佈局
```
┌──────────────────────────────────────┐
│ [IntelliPlex]  2025/06/15 14:30      │
│ 17 samples • Completed               │
│ Program: ExtractionV2  Op: operator   │
└──────────────────────────────────────┘
```

### 欄位細節

| 元素 | 字體 | 說明 |
|------|------|------|
| 類型徽章 (badge) | 16pt Bold | 藍底/橙底圓角標籤 |
| 日期 | 18pt | `yyyy/MM/dd HH:mm` 完整格式 |
| 樣本數 + 狀態 | 18pt | `17 samples • Completed` |
| 程式名 | 17pt | `ExtractionProgram` 截取 24 字元 |
| 操作員 (Admin) | 17pt | 藍色文字，右對齊 |

---

## Compact 模式 (`compact`)

**設計定位**：單行高密度，適合大量紀錄的快速掃描。

### 視覺佈局
```
● 06/15   17smp   Completed            operator
● 06/14   23smp   Error ⚠              admin
```

### 欄位配置（600px 面板）

| 欄位 | 寬度 | 字體 | 說明 |
|------|------|------|------|
| 色碼點 | 16px | — | 藍=IntelliPlex / 橙=QPLEX |
| 日期 | 90px | 19pt | `MM/dd` 短格式 |
| 樣本數 | 80px | 18pt | `{count}smp` + 8px 右間距 |
| 狀態 | Star | 18pt | 綠/紅/橙 + ⚠ 圖示 |
| 操作員 | 150px | 18pt | Admin 時顯示，截取 18 字元 |

**剩餘空間**：狀態欄 = 600 - 16 - 90 - 80 - 150 = **264px**

---

## Table 模式 (`table`)

**設計定位**：類似 Excel 的表格體驗，支援排序，適合資料分析與比對。

### 視覺佈局
```
 Date ▼    Type      Samples   Status       Operator
──────────────────────────────────────────────────────
 06/15     ● IPlex      17     Completed    operator
 06/14     ● QPlex      23     Error ⚠      admin
 06/13     ● IPlex       8     Completed    operator
```

### 欄位配置（600px 面板）

| 欄位 | 寬度 | 字體 | 說明 |
|------|------|------|------|
| 日期 | 100px | 16pt | `MM/dd` 短格式 |
| 類型 | 90px | 14pt | 色碼點 + `IPlex`/`QPlex` 縮寫 |
| 樣本 | 80px | 16pt | 純數字，置中對齊 |
| 狀態 | Star | 16pt | 翻譯文字 + ⚠ 圖示 |
| 操作員 | 120px | 14pt | Admin 時顯示，截取 14 字元 |

### 排序功能

| 操作 | 行為 |
|------|------|
| 點擊表頭 | 切換該欄升冪 ▲ / 降冪 ▼ |
| 切換排序欄 | 日期預設降冪，其他欄預設升冪 |
| 排序指示 | 當前排序欄高亮藍色 + ▲/▼ |

### 視覺特效

| 效果 | 說明 |
|------|------|
| 表頭底線 | 2px 藍色分隔線 |
| 交替底色 | 奇數行 `#1E2D4A` / 偶數行 `#16223A` |
| 按壓效果 | 點擊時背景變為 `#2A4570` |

---

## 共通功能

三種模式共享以下互動功能：

| 功能 | 說明 |
|------|------|
| **點擊** | 進入 DataDetailPage |
| **長按** | 進入多選模式 |
| **多選 CheckBox** | 放大 1.6 倍，垂直置中 |
| **權限篩選** | Operator 僅顯示自己的紀錄 |
| **Admin 篩選列** | 報告類型下拉 + 全部/我的切換 |
| **語系即時更新** | 切換語系後立即重繪列表 |

---

## 切換方式

### 資料庫設定
```sql
UPDATE system_settings 
SET value = 'table'  -- card | compact | table
WHERE key = 'data_list_layout';
```

### 頁面內切換
頂部列右側的版面切換按鈕（卡片/列表/表格圖示）。
