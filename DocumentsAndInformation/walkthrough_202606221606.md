# USB 讀取背景檢查（usb_read_background_check）重構 Walkthrough

**作者 / 變更分析：Office of William**

## 變更總覽

本階段針對 **TRIO2026 報表系統** 的 USB 讀取背景安全性進行重構：

1. **讀取背景檢查（usb_read_background_check）流程重構**：
   - **移出匯出下載流程**：自 `DataListPage.xaml.cs` 及 `DataDetailPage.xaml.cs` 匯出步驟中移除不適用的背景讀取掃描。
   - **移入實體插入偵測**：當隨身碟插入時（`ProcessQueueAsync`），**先執行格式化檢查**（詢問是否格式化非空碟），若使用者選擇**取消格式化**（保留碟片內容），才進入讀取背景檢查。
   - **已格式化跳過掃描**：若使用者選擇確認格式化，碟片內容已清空，則直接跳過背景檢查。

2. **設定值擴展與實作**：
   - `0` = 不執行檢查。
   - `1` = 檢查並阻擋（偵測威脅時跳出 Error 警示，阻擋後續使用）。
   - `2` = 檢查並提示（偵測威脅時跳出 Warning 警示，等待使用者點選「我已了解」確認後解除等待並記錄）。

3. **完整資安埋點鏈**：
   - 新增 `INF-4025` ~ `INF-4028` 四組事件代碼。
   - 補齊 AppShell 警示彈窗顯示、使用者點選「確定」/「我已了解」的行為日誌。

4. **資料庫設定 Seed 同步**：
   - 補齊 `SystemSettingSeed.cs` 中缺少的 13 筆執行期動態產生設定（`hw_*`, `os_*`, `installation_*` 等），達成 Seed 檔與 SQLite DB 欄位之完全一致。

## 日誌埋點鏈條示範 (以 Mode=2 偵測威脅為例)

```
1. [INF-4010] USB Device Inserted
2. [INF-4020] USB Format Prompt Shown
3. [INF-4013] USB Format Cancelled
4. [INF-4025] USB Read Check Started (Mode=2)
5. [WRN-4016] USB Threat Detected (偵測到非法格式檔案，如 .exe)
6. [WRN-4027] USB Read Check Threat Found (Mode=2, Action=WaitingAcknowledgement)
7. [WRN-4027] USB Read Check Warning Dialog Shown (AppShell UI 顯示彈窗)
8. [INF-4028] USB Read Check Warning Acknowledged by User (使用者點選我已了解)
9. [INF-4028] USB Read Check User Acknowledged (解鎖背景執行緒)
```
