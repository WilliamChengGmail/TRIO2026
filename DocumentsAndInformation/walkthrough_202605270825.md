# 實驗數據落地 DB — Walkthrough

## 變更摘要

本次實作將 TRIO2026 的實驗數據架構從「直接產出 Excel」遷移為「數據優先落地 DB，報告按需生成」。

### Phase 1: Entity & Schema 擴充

#### 修改的檔案

| 檔案 | 變更 |
|------|------|
| [TestRecord.cs](file:///d:/TRIO2026/src/TRIO2026.Core/Entities/TestRecord.cs) | 新增 ~20 個欄位：實驗參數、操作員審計、設備資訊 |
| [SampleResult.cs](file:///d:/TRIO2026/src/TRIO2026.Core/Entities/SampleResult.cs) | 新增 SampleId、ElutionTubeId、ConcentrationDisplay、PCR Well x4 |
| [ReportSnapshot.cs](file:///d:/TRIO2026/src/TRIO2026.Core/Entities/ReportSnapshot.cs) | 新增 GeneratedByUserId/Username、ExcelFilePath、PdfFilePath |
| [DataDbContext.cs](file:///d:/TRIO2026/src/TRIO2026.Data/Contexts/DataDbContext.cs) | DB 改名 data.db、新增操作員/日期/報告類型索引 |
| [DatabaseInitializer.cs](file:///d:/TRIO2026/src/TRIO2026.Data/Extensions/DatabaseInitializer.cs) | 新增 InitializeDataDbAsync() |
| [App.xaml.cs](file:///d:/TRIO2026/src/TRIO2026.App/App.xaml.cs) | 加入 DataDbContext DI 註冊 |

#### 設計決策
- 所有實驗參數欄位預設 **nullable**，待 flow/firmware 規格明確後再加必填約束
- Custom PCR Setup 使用 **JSON** 存儲（`CustomPcrSetupJson`），支援未來 Rxn 數量擴充
- 操作員資訊以**快照方式**存於 TestRecord（跨 DB 不設 FK），確保帳號刪除後記錄仍完整
